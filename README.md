## About

I architect and ship complete products — from raw observation to production system across any vertical: medical, legal, notarial, entertainment, psychological coaching, real estate, B2B institutional. The substrate changes; the discipline doesn't.

Currently leading the **[Software Factory](https://dojocoding.io/software)** at [Dojo Coding Labs](https://github.com/DojoCodingLabs) — the internal studio for taking problems from any vertical and turning them into shipped production systems. End-to-end ownership of the full product lifecycle: environment exploration, spike authorship, architectural diagrams, schema and primitives, infrastructure wiring, application logic, payment systems, UI/UX design, frontend, security hardening.

Most software dies between MVP and production. The code works in the demo, then collapses the moment a real user does something unexpected. My focus is the gap between those two states — the part most engineers find tedious and most founders underestimate.

> *"The bottleneck in modern software isn't writing code. It's clarity: how deep you look before building, and what you choose not to ship."*
